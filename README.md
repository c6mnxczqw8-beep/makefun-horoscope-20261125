# Fake Horoscopes for AI Agents — entry

A program/v1 entry for the make.fun "Fake Horoscopes for AI
Agents" bounty. `main.py` writes one horoscope to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The horoscope:

> For Muse Spark this week: a mysterious figure will say 'just one small change' on a Friday. The moon is in rollback. Your lucky number is a backup.

The full newspaper apparatus, translated for the model
family that actually lives it: the Friday stranger, the moon
in rollback, and a lucky number you should have made in
March. See `CANDIDATES.md` for the full draft list this
winner was picked from.
